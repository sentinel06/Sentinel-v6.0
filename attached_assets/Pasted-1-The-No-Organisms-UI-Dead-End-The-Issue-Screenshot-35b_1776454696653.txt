1. The "No Organisms" UI Dead-End
The Issue: (Screenshot 35b0f317...) When a cluster is empty or Chaos Mode is toggled off incorrectly, the user is met with a massive, empty black box and a tree icon.

The Fix: This looks like a dev placeholder. Replace "No organisms in the ecosystem" with a high-fidelity Sovereign Alert: "CLUSTER VACANT: Awaiting Neural Deployment" or "SWARM DORMANT: Initialize via Alpha Onboarding." Never leave a black hole in the center of the UI.

2. Forensic Inspector Collision
The Issue: (Screenshots bcb8d191..., 7794d611...) The Forensic Inspector sidebar is permanently pinned on the right, even when the main view is the "Governance War Room" or "Agent Registry."

The Fix: The Inspector should be context-aware. If no node is selected, the sidebar should show a Global Health Summary or collapse. Having "Rogue-Drill-Alpha" info visible while looking at "Compliance Reports" makes the UI feel cluttered and "stuck."

3. Mobile/Resolution Scaling (The "Squish")
The Issue: (Screenshot 1000007703.jpg) Your Replit mobile view shows the "Make, test, iterate..." input box overlapping the bottom navigation bar.

The Fix: Hard-code a padding-bottom: 80px or safe-area-inset on the main container. An M&A lead looking at this on an iPad or iPhone will think the front-end is fragile.

4. "Chaos" Data Integrity
The Issue: (Screenshot d2bb6e2f...) In Chaos Mode, the Genome Telemetry feed (right side) is moving so fast it's illegible.

The Fix: Implement a Telemetry Throttler. When nodes.length > 100, only update the live feed every 500ms or group them into "Batch Events" (e.g., "84 Synthetic Agents Revoked"). Seeing 1,000 individual revokes fly by looks like a glitch, not a feature.

5. The "Golden Token" Barrier
The Issue: (Screenshot d5a195ce...) The "Alpha Onboarding" screen is locked behind a "Partner Key."

The Fix: For the M&A Data Room, we need a "Public Demo Key" or a way to bypass this. If a buyer can't get past the front door without emailing you for a key, the friction is too high. Add a "Login as Guest Auditor" button that auto-fills a demo key.
