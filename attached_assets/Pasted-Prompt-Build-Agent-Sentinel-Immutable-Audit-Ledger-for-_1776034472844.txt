Prompt: Build "Agent-Sentinel" – Immutable Audit Ledger for AI Agents
Role: You are a Senior Backend Engineer and Compliance Architect.
Goal: Build a centralized, immutable audit logging system designed to meet EU AI Act Article 12 standards for traceability and accountability of autonomous AI agents.

1. Core System Architecture
Tech Stack: Node.js (Express) or Python (FastAPI), PostgreSQL via Replit Database/Postgres, and a React-based monitoring dashboard.

The Ledger (Database): Create a audit_logs table.

Fields: id (UUID), timestamp (UTC), agent_id (String), trace_id (String for multi-step tasks), event_type (Intent/Action/Result/Error), payload (JSONB for raw data), rationale (Text for Chain-of-Thought), and previous_hash (String for integrity).

Immutability: Configure the database with a trigger that prevents any UPDATE or DELETE actions on the audit_logs table.

2. API Requirements
Build a secure REST API with the following endpoint:

POST /v1/log: Receives an audit packet.

Security: Implement a "Sentinel-Key" (API Key) check via Replit Secrets.

Logic: For every new entry, calculate a SHA-256 hash of the (timestamp + agent_id + payload + previous_hash) and store it. This creates a cryptographic chain of events.

3. The "Human-in-the-Loop" (HITL) Dashboard
Create a clean, high-density React dashboard with:

Live Stream: A real-time feed of agent actions using WebSockets.

Trace View: A view that groups logs by trace_id so I can see the full lifecycle of a single AI decision (e.g., "User Request" -> "Agent Logic" -> "Tool Call" -> "Success").

Anomaly Flagging: Highlight any log where event_type == 'Error' or where the rationale field contains high-risk keywords (e.g., "Access Denied," "Financial Transfer," "Data Export").

4. Compliance Features (Article 12 Ready)
Export Tool: A button to generate a CSV or JSON "Compliance Report" for a specific agent_id within a time range.

Health Check: A background task that verifies the "Hash Chain" every hour. If any hash in the database doesn't match the chain, flag a "Tamper Alert" on the dashboard.

5. Initial Milestone
Set up the PostgreSQL schema with the immutability trigger.

Create the POST /v1/log endpoint and test it with a sample Python script mimicking an AI Agent.

Deploy the basic React UI to display these logs.

Instructions for Agent: Focus on data integrity first. If you encounter an error with the database triggers, explain the logic before proceeding. Do not add "fluff" or placeholder text; use professional logging formats.
